# GLUE Web User Interface

A modern web-based user interface for the GLUE (Generalized Likelihood Uncertainty Estimation) parameter estimation tool.

## Features

- **Easy Configuration**: Visual interface for setting up all GLUE parameters
- **Directory Management**: Browse and select directories for DSSAT, GLUE, output, and genotype files
- **Real-time Status**: Monitor GLUE execution progress
- **Results Viewer**: View output files, warnings, and run indicators
- **Cross-platform**: Works on Windows, macOS, and Linux

## Requirements

- R (version 3.5 or higher)
- R packages: `shiny`, `shinydashboard`, `shinyjs`, `parallel`
- DSSAT installed and configured
- GLUE R scripts (included in this repository)

## Installation

The required R packages will be automatically installed when you first run the UI. If you prefer to install them manually:

```r
install.packages(c("shiny", "shinydashboard", "shinyjs", "parallel"))
```

## Usage

### Starting the UI

**Windows:**
```bash
run_ui.bat
```

**macOS/Linux:**
```bash
./run_ui.sh
```

**Or directly with R:**
```bash
Rscript run_ui.R
```

The application will open in your default web browser at `http://127.0.0.1:3838`

### Using the Interface

1. **Configuration Tab**:
   - Set all directory paths (GLUE, DSSAT, Output, Genotype)
   - Configure model parameters (Model ID, GLUE Flag, Number of Runs, etc.)
   - Click "Save Configuration" to create `SimulationControl.csv`

2. **Run GLUE Tab**:
   - Click "Run GLUE" to start the calibration process
   - Monitor progress in the status window
   - The process may take a while depending on the number of runs

3. **Results Tab**:
   - View output files generated by GLUE
   - Check for warnings or errors
   - Review model run indicators

## Configuration

The UI generates a `SimulationControl.csv` file in the current working directory with the following parameters:

- `CultivarBatchFile`: The batch file to use (e.g., NEWTON.WHC)
- `ModelID`: DSSAT model identifier (e.g., CSCRP048)
- `EcotypeCalibration`: Whether to calibrate ecotype coefficients (Y/N)
- `GLUED`: Path to GLUE directory
- `OutputD`: Path to output directory
- `DSSATD`: Path to DSSAT installation
- `GLUEFlag`: Calibration mode (1=both, 2=phenology, 3=growth)
- `NumberOfModelRun`: Number of Monte Carlo simulations
- `Cores`: Number of CPU cores to use
- `GenotypeD`: Path to genotype files directory

## Notes

- The UI runs GLUE synchronously, so the browser may appear unresponsive during execution
- For very long runs, consider using the command-line version: `Rscript GLUE.r`
- Make sure all paths are correctly set before running GLUE
- The output directory should be different from the GLUE working directory

## Troubleshooting

**UI won't start:**
- Make sure R is installed and in your PATH
- Check that required packages are installed
- Verify you're running from the GLUE directory

**Directory selection not working (macOS/Linux):**
- Use the text input dialogs that appear when clicking "Browse"
- Enter full paths manually

**GLUE execution fails:**
- Check that `SimulationControl.csv` was created correctly
- Verify all directory paths exist
- Ensure DSSAT is properly installed
- Check the warnings file in the output directory
